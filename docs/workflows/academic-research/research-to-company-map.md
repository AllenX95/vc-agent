# Research-to-Company Map — Prompt-first Prototype v1

Use to identify candidate commercialization organizations associated with a paper, author group, lab, GitHub organization, or Hugging Face organization.

Read [the shared evidence policy](references/evidence-policy.md) before executing.

## Workflow

```text
paper
→ author candidates
→ institution/lab
→ GitHub/HF user or organization
→ repository/model/dataset/Space
→ organization home-page or commercial-domain signal
→ candidate commercialization organization
```

Strong evidence includes explicit paper IDs, cross-links, matching organizations, or author-linked assets. Medium evidence combines several consistent ownership, title, author, and technical-route signals. Name similarity alone is weak evidence.

## Required output

| Candidate organization | Related research | Core people | GitHub/HF assets | Evidence | Confidence |
|---|---|---|---|---|---|

Use the terms:

```text
候选商业化组织
疑似产业化主体
可能存在关联
```

Do not write “confirmed company mapping” using only these four sources. Do not infer employment, incorporation, financing, IP ownership, or commercial deployment.

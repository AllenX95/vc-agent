# Use Evidence Discipline Instead Of An Evidence Gate

Accepted: VC Deliverables use best-effort Evidence Discipline rather than requiring every investment view to be proven or cited. Verifiable facts should remain traceable, while user judgment, model inference, hypotheses, intuition, and aesthetic assessment are allowed under uncertainty as long as they are not misrepresented as source facts. This protects factual auditability without suppressing the subjective reasoning that is central to VC work.

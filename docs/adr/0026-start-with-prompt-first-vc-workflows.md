# Start With Prompt-First VC Workflows

Accepted: the first release keeps the Codex-like conversation surface and verticalizes it through the base VC system prompt and Host-registered Capabilities, without requiring bundled First-party VC Skills. Compatible external Skills and explicit Skill Creator remain available, but First-party VC Skills should be created only after real Prompt-first Validation reveals stable repeated workflows and best practices. This prioritizes getting the product into use and avoids prematurely freezing speculative workflow design.

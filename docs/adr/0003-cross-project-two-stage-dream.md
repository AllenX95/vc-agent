# Use Cross-Project Two-Stage Dream

Accepted: every Dream session reviews short-term memory candidates across all projects, not only the project from which Dream was launched. Dream first creates project-level summaries for user review, then performs a global synthesis to propose durable personal VC investment learning.

This makes Dream serve the user's cross-project investment judgment rather than becoming another project cleanup tool. The trade-off is a more structured review flow and a stronger requirement that each candidate carries reliable project metadata.

The first-stage isolation unit is the Project, not the individual Thread. One Project Dream Extraction Pass may inspect multiple Eligible Dream Trajectories belonging to that Project through bounded retrieval, but it cannot receive another Project's raw trajectory. It emits only a bounded Project Dream Summary, structured candidates, uncertainty, and stable source references. Global Dream Synthesis receives those project-level results after review and never receives the combined raw trajectories of all Projects.

Unscoped Threads remain eligible but are not grouped into a synthetic Project. Each Unscoped Thread uses its own Unscoped Dream Extraction Pass and sends only a bounded reviewed result into Global Dream Synthesis. Because the source has no Project association, its proposals may target Long-term Memory, Keep Pending, or Discard, but never Project Memory.

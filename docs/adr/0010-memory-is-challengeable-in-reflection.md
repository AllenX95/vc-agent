# Treat Memory As Challengeable Evidence In Reflection

Accepted: the Investment Reflection Thread system prompt gives the LLM a Critical Reflection Stance. Project and Long-term Memory describe the sole User's prior views but do not outrank current project evidence and may be challenged when reasoning or evidence warrants it; the agent must explain disagreement and must not perform reflexive opposition. This trades some conversational comfort and consistency for protection against sycophancy, confirmation bias, and the accumulation of untested beliefs.

# Recover Missed Memory Signals During Dream

Accepted: Dream reviews both previously captured Short-term Memory Candidates and relevant Thread trajectory after the prior committed Dream Cutoff and up to the current batch's Dream Cutoff, plus any explicit Dream Carryover, to recover strong user signals that live capture missed. Every recovered signal remains a Recovered Memory Candidate with a traceable source and requires the same review and final patch confirmation as a captured candidate.

This reduces dependence on perfect real-time classification and makes Dream a genuine memory-consolidation mechanism rather than only a queue cleaner. The trade-off is broader read access and additional model cost during an approved Dream run, so discovery is bounded to the review period and eligible source types. User statements, user corrections, confirmed Judgment Records, and explicit Memory actions may support recovery; arbitrary model output, source documents, OCR, and web content cannot become Memory merely because they appear in trajectory.

Eligible Dream Trajectory includes Project Threads, Unscoped Threads, and the user-facing Memory-Aware Reflection dialogue because each may contain attributable personal investment judgment. It excludes Dream and other system-maintenance sessions, Independent Evidence Pass contexts, background helper or subagent sessions, and pure tool trajectories. Results from an excluded context become eligible only when they are later presented to and meaningfully adopted, corrected, or confirmed by the User in an eligible conversation.

The L5 implementation maintains a content-free eligibility index containing stable Thread/Turn references, scope, Project Identity where applicable, and completion timestamps. Ordinary completed user-facing exchanges are eligible; Reflection exchanges additionally require the persisted adoption, correction, or confirmation marker. Archived Threads stay in selection, while explicitly deleted trajectory is removed before selection. Batch creation, not the Due Check, resolves the bounded source text behind those references.

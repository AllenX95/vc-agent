# Ship A Usable Vertical Alpha As MVP

Accepted: the first release is a usable VC Desktop Agent vertical alpha, not only a host/runtime infrastructure proof. It includes real document parsing, task-specific source-referenced Outputs, Office generation and editing through compatible document Skills, one Configured OCR Capability when available, Dream memory consolidation, Skill Creator, and compatible complete Skill package import into the VC Agent Skills Directory using Pi's native loading mechanics.

Dream is part of the first usable memory loop rather than a later optimization. Its first-release depth is a basic but complete path from accumulated Short-term Memory Candidates and auditable source trajectory, through an isolated consolidation pass and user-reviewed proposal, to an explicitly approved Project Memory or Long-term Memory patch. Heavy runtimes such as bundled OCR engines, LibreOffice, full Office-editor replacement, skill marketplaces, and automatic skill creation remain out of scope.

Delivery is staged without reducing that release scope. Foundation establishes the real Pi desktop runtime; Dogfood Build adds the end-to-end daily path through prompts, materials, web, Outputs, Context, and Project Memory; Learning Build closes Long-term Memory, Reflection, Dream, backup, and migration; Integration Build adds Office, OCR, MCP, isolated Skills, and Skill Creator; Delegation And Hardening adds explicit Sub-Agent Runs, bounded concurrency, recovery, and the complete acceptance suite. The sole User begins real work at Dogfood Build, but only completion of every stage is called the first complete Personal Build. This favors early practical feedback over a long simultaneous build while preserving the full vertical-alpha commitment.

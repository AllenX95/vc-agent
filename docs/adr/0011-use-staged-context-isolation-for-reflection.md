# Use Staged Context Isolation For Investment Reflection

Accepted: Investment Reflection uses a multi-agent-style two-stage flow with isolated model contexts in either Project or Unscoped scope. An Independent Evidence Pass analyzes evidence authorized by that Thread scope without personal memory and hands a bounded, evidence-referenced Independent Assessment to a separate Memory-Aware Reflection Pass; raw materials, the first-stage transcript, and full model reasoning are not copied forward. The second pass may retrieve bounded authorized excerpts through Evidence Drilldown when a cited claim needs verification, but it must not reload complete materials. This reduces context growth and memory anchoring while preserving auditability and Project isolation, at the cost of maintaining an explicit intermediate handoff and potentially performing additional model calls.

A Project Reflection may start from the broad objective `Review this Project`; the User does not need to define a narrower question or preselect materials. Broad launch gives the Independent Evidence Pass only a bounded, non-memory Reflection Project Brief and lets it choose evidence through Progressive Material Disclosure. It does not preload the whole Project, Project Memory, Long-term Memory, or prior investment conclusions.

After the Independent Assessment exists, the Memory-Aware Reflection Pass may autonomously retrieve relevant active Project Memory and Long-term Memory through bounded card-then-expand recall. Relevance may be direct through Local Memory Provenance linking a learning to the current Project, or inferred from the Project brief and assessment, including industry, financing stage, applicability, risk, diligence questions, counterarguments, and uncertainty. Direct provenance may raise retrieval priority but does not make a memory correct or turn it into source evidence. Ordinary recall remains de-identified and visible, unresolved conflicts are recalled together, and `explicit-only` Long-term Memory still requires explicit User intent.

The Reflection run freezes a Workflow Prompt Snapshot at launch. Both stages and any explicit post-restart resume use that System Prompt Revision even if the active revision changes meanwhile, preventing one Judgment Record or Long-term Learning Proposal from being formed under mixed base instructions.

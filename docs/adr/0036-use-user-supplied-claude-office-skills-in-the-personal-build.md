# Use User-Supplied Local Office Skills In The Personal Build

Superseded: the first usable release remains a Personal Build for the sole User, but Office packages are now accepted only through explicit local import/provisioning. vc-agent keeps compatibility changes in a Host-owned overlay where practical and records package provenance as sanitized metadata; it does not include third-party Office packages, vendor URLs, pinned revisions, or automatic download logic in the repository or installer.

# Use User-Supplied Claude Office Skills In The Personal Build

Accepted: the first usable release is a Personal Build for the sole User and directly invokes complete Claude Code `docx`, `pptx`, `xlsx`, and `pdf` Skill packages that the User supplies to the isolated VC Agent Skills Directory. vc-agent keeps compatibility changes in a Host-owned overlay where practical and records any local package diff, but it does not include those third-party packages in its repository or installer, claim ownership or redistribution rights, or assume they can ship in a later distributable product.

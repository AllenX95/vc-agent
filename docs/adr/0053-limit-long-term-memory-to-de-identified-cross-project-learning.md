# Limit Long-Term Memory To De-identified Cross-Project Learning

Accepted: Long-term Memory contains reusable personal investment cognition whose maximum specificity is an industry, financing stage, or comparable cross-project investment situation. Named-company facts, unpublished metrics, transaction terms, material excerpts, and project-specific conclusions remain in Project Memory or Project materials. Dream must de-identify a project-derived principle before proposing it for Long-term Memory, and Global Dream Synthesis receives de-identified summaries with opaque source references rather than Project identity or unnecessary deal-level facts.

Ordinary model-facing Long-term Memory recall contains the current abstract learning, applicability, limitations, maturity, tags, and conflict state, but excludes local source Project identity, paths, original excerpts, and deal-level provenance. Local provenance remains inspectable by the User and may be drilled into only from the source Project during explicit Reflection or verification under that Project's Provider Authorization.

An entry may be marked `Explicit Recall Only`, excluding it from Automatic Judgment Recall while allowing explicit User recall. Direct User edits remain authoritative; apparent project-specific content triggers a warning and destination suggestion rather than blocking or automatic rewriting. This preserves useful cross-project personalization across third-party Providers without building a DLP engine or per-Provider Memory ACL, at the cost of abstraction discipline and limited provenance in ordinary recall payloads.

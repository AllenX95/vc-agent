# Use Microsoft Office For Windows Office Outputs

Accepted: the Windows Personal Build uses the installed Microsoft Office desktop applications as its Office Output provider, with DOCX create/edit/reopen/render operations executed through an isolated Microsoft Word runner. LibreOffice and vc-agent-owned parallel document engines are not provider or fallback paths; missing Office remains a visible unavailable state. Imported Office Skills and their active revisions live only in the dedicated VC Agent Skills Directory under vc-agent application data, never in another agent's live Skills root.

# Keep VC Workflows Conversation-First

Accepted: the product retains a Codex-like Thread and Prompt Composer as its primary interface. Stable VC actions are Host-registered Capabilities, while bundled First-party VC Skills organize those capabilities, prompts, evidence rules, and output standards into professional workflows invoked inside the Thread. This preserves open-ended agent collaboration and skill reuse while rejecting separate form-heavy applications for each VC task, at the cost of making workflow progress and required inputs clear within conversation.

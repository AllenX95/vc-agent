# Preserve Material Human-Model Judgment Disagreement

Accepted: the LLM may form independent investment judgments and write VC Deliverables in a coherent professional voice, but a disagreement with the User that could materially change the conclusion, risk assessment, core rationale, or action must remain explicit until resolved or deliberately kept open. Final Output approval accepts the document without automatically promoting its judgments to Memory. This preserves the value of an independent thinking partner while preventing polished prose from manufacturing false consensus.

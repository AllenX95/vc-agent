# Recall Project Context On Demand

Accepted: new Project Threads start without Project Context or a generated startup digest in model context. The Agent retrieves only relevant fixed-template sections through visible, bounded Project Context Recall when the conversation needs project working state or the User explicitly requests it; Unscoped Threads cannot use the recall. This reduces startup tokens and keeps Threads Codex-like, at the cost of relying on task-time recall instead of guaranteed background awareness.

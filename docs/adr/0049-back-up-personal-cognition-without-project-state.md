# Back Up Personal Cognition Without Project State

Accepted: the first release provides an explicit Personal Cognition Backup containing durable user-level cognition and reconstructible personal configuration. It includes Long-term Memory, Cognitive Evolution History, Condensation Archive, System Prompt Revisions, Model Profiles and task assignments, non-secret settings, and the VC Agent Skills Directory. Thread and Sub-Agent trajectories are optional and excluded by default. The transparent bundle is versioned and checksummed but not encrypted by vc-agent.

The backup excludes Project registration and identity metadata, paths, Materials, Outputs, Project Context, Project Memory, artifact state, project-scoped Dream progress and pending queues, resumable workflow state, logs, caches, and all Protected Credentials. Confirmed Dream results remain protected only after they have entered the durable user-level cognitive record. The backup therefore does not migrate workspaces, recreate Projects, resume interrupted work, or require a Project Relink mechanism.

Restore is permitted only into empty personal state or as an explicitly confirmed whole-domain replacement. It preserves included record lineage but does not use an LLM to merge Memories or synthesize missing provenance; links to excluded Project sources remain unavailable. This keeps disaster recovery small and predictable and avoids exporting directory topology or manufacturing a false cognitive history, at the cost of requiring separate user-managed Project backups and fresh credential configuration.

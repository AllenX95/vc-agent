# Store Memory Review State At App Level

Accepted: short-term memory candidates, Dream batches, and Dream review archives are stored in app-level memory state, not in each project folder. Project folders keep confirmed project memories in `outputs/system/project-memory.md`, while the pre-commit review queue for personal investment learning remains private application state.

This avoids cluttering project folders with transient personal memory workflow files. The trade-off is that moving a project folder does not carry every pending memory candidate with it; candidates instead reference projects, threads, and outputs by metadata from the app-level queue.

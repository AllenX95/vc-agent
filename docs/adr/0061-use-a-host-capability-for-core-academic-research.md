# Use A Host Capability For Core Academic Research

Accepted: OpenAlex, arXiv, GitHub, and Hugging Face research is one Host-registered `academic_research` Capability backed by one deep AcademicResearch Module and four internal Source Adapters. It is not a Pi Extension, a set of source-specific model tools, an MCP Server, or a silent fallback to general web scraping.

Academic research is a core VC evidence path. Host ownership keeps scope enforcement, task-activated visibility, Capability Gateway execution, bounded retrieval, Context References, source warnings, protected credential resolution, and trajectory auditing at the existing product seam. The model learns one intent-level Interface while the Module hides source selection, API changes, rate limits, normalization, deduplication, evidence construction, and artifact linking.

The Tool returns source facts and relationship confidence, not final claims about novelty, SOTA, founder quality, company ownership, conference acceptance, employment, financing, patents, customers, or deployment. arXiv remains a preprint source; OpenAlex publication indexing does not independently verify a venue decision; README and Hub Cards remain publisher or author claims; negative search does not prove non-existence.

Paper PDF bytes are downloaded only into bounded app-data staging, hash-checked, parsed by the Utility Worker, exposed as bounded evidence excerpts, and deleted after the task. The prototype does not redistribute or serve arXiv e-prints. Current arXiv legacy API policy is one connection and at most one request every three seconds across the machines under the User's control; the Adapter owns this versioned policy.

Five initial VC workflows remain Prompt-first prototypes: paper technical diligence, founder academic diligence, technical claim verification, novelty/prior-work mapping, and research-to-company mapping. They may enter the task context when explicit natural-language intent matches, but they do not become bundled First-party Skills until Golden Cases and real use demonstrate stable instructions and output contracts. Any promoted package goes through the existing single VC Agent Skills Directory and contains its own referenced policy files.

OpenReview, Crossref, legal patent search, company registry, financing data, private repositories, gated Hub content, external-code execution, and MCP interoperability are outside v0.1. A future MCP Adapter may reuse the AcademicResearch Module only after a second concrete caller exists; it must not move VC judgment into the interoperability layer.

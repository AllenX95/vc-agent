# Use Versioned Long-Term Memory Evolution

Accepted: Long-term Memory evolves through explicit user-approved Add, Reinforce, Narrow, Revise, and Contradict actions rather than append-only notes or silent replacement. Revised or narrowed learning preserves its earlier version and provenance, while insufficiently resolved disagreement remains an Unresolved Memory Conflict. This keeps active Long-term Memory usable while making cognitive change auditable, at the cost of stable memory identities, version lineage, and conflict handling.

Dream may detect relationships and propose these actions, but it cannot resolve a substantive conflict by treating the newest, most repeated, or most strongly worded view as authoritative. `Revise` requires an attributable User correction or a later user-approved Reflection or Retrospective conclusion that explicitly changes the earlier judgment. Otherwise Dream proposes `Contradict` and preserves an Unresolved Memory Conflict; wording-only overlap may instead use merge or condensation.

This classified evolution contract applies to Agent-proposed and app-mediated memory changes. The User may directly edit `long-term-memory.md`; after change detection, that Manual Memory Edit becomes the authoritative active content and the app rebuilds its derived index without calling a model or requiring another confirmation. It records the change as manual but does not infer `Add`, `Narrow`, `Revise`, or `Contradict`, and does not synthesize Cognitive Evolution History from the diff. A direct deletion takes effect without automatic Condensation Archive or Cognitive Evolution History. Any pending proposal based on the previous file version becomes stale and cannot be automatically merged over the manual edit.

Manual authorship does not make an entry immutable or more truthful than other Memory. Dream and Investment Reflection may challenge it and propose `Narrow`, `Revise`, or `Contradict` when later reasoning or evidence warrants, but the proposal changes Memory only after the same explicit User review and confirmation required for any other entry.

Dream may also propose organizing, condensing, or promoting a manually authored Project Memory entry into Long-term Memory, but promotion preserves its `User-authored / no evidence provenance` status. Only a User-confirmed Reflection or Investment Retrospective conclusion with traceable supporting evidence may raise its maturity to evidence-backed or retrospectively supported learning.

# Novelty And Prior-Art Map

Treat prior art here as academic predecessor research, not a legal patent opinion.
Use Extension-owned `web_fetch` for generic public pages and GitHub repository content; activate it through `capability_request` when needed. Keep normalized works, identifiers, evidence types, and graph links in `academic_research`.

## Workflow

1. Read [references/evidence-policy.md](references/evidence-policy.md).
2. Define the seed work or technical claim and decompose it into core modules.
3. Search references, citations, related works, contemporary arXiv papers, and public artifacts.
4. Classify each work as foundational, direct predecessor, parallel, alternative, successor, implementation, or reproduction.
5. Record only evidence-backed relationships.
6. Apply [references/methodology.md](references/methodology.md).

## Required output

Provide a technical definition, chronology, route clusters, the seed's incremental contribution, alternative paths, reproducibility evidence, substitution risk, and unresolved gaps. Include graph-ready nodes and edges when useful.

## Boundaries

Do not present this workflow as a freedom-to-operate or patentability search.

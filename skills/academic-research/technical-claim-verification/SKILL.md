# Technical Claim Verification

Use `academic_research` to test each atomic claim against papers and public artifacts.

## Workflow

1. Read [references/evidence-policy.md](references/evidence-policy.md).
2. Split the original statement into independently testable claims.
3. Define what each ambiguous scale, benchmark, or superlative means.
4. Search supporting evidence and deliberate counterevidence.
5. Check whether code, model, dataset, hardware, and evaluation conditions match the wording.
6. Apply [references/methodology.md](references/methodology.md).

## Required output

Produce a claim matrix with the atomic claim, verdict, supporting evidence, limitations or counterevidence, and a safe rewritten statement. Use only: verified, broadly supported, partially supported, conflicting evidence, unverifiable, or refuted.

## Boundaries

Failure to find prior work does not prove novelty. Author-reported results are not independent validation.
